---
title: std.env
description: Environment variables and CLI arguments
---

```zz
import std.env
```

| Function | Signature | Description |
|----------|-----------|-------------|
| `env.get_var` | `env.get_var(name: str)` | Variable value (`Option`) |
| `env.var` | `env.var(name: str)` | Variable value (`Option`) |
| `env.args` | `env.args() -> [str]` | Script arguments |

```zz
import std.env

match env.get_var("HOME") {
    .some(home) => println("Home: {home}"),
    .none => println("HOME not set"),
}

for arg in env.args() {
    println(arg)
}
```
