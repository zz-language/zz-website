## Install

<Tabs>
  <TabItem label="Install script">
    ```bash
    curl -fsSL https://zz-lang.pages.dev/install.sh | sh
    ```
  </TabItem>
  <TabItem label="From source">
    ```bash
    git clone https://github.com/zaidejjo/zz
    cd zz
    cargo install --path crates/zz_cli
    ```
  </TabItem>
</Tabs>

Verify the install:

```bash
zz --version
```

## Hello world

Create `hello.zz`:

```zz
name := input("What is your name? ")
println("Hello, {name}!")
```

Run it:

```bash
zz run hello.zz
```

## The REPL

Start an interactive session with bare `zz`:

```
ZZ 0.1.0 — type-based language
Type expressions to evaluate. :help for commands.
zz> x := 42
42
zz> x + 1
43
zz> func add(a: int, b: int) -> int { a + b }
<func add>
zz> add(3, 4)
7
```

Useful REPL commands: `:help`, `:type expr` to show a type, `:clear` to reset bindings, `:quit` to exit.

## Your first real program

```zz
func factorial(n: int) -> int {
    if n <= 1 { 1 } else { n * factorial(n - 1) }
}

println("5! = {factorial(5)}")
```

```
5! = 120
```

## Check, fix, format

ZZ ships its diagnostics as commands:

```bash
zz check src/     # report errors and warnings
zz fix src/       # apply safe auto-fixes
zz fmt src/       # format files in place
zz eval "1 + 2"   # evaluate one expression → 3
```
