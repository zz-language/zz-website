## Install

The install script is the main way to install ZZ. It fetches the latest
release from GitHub, installs to `~/.zz/bin`, and wires up your shell.
Re-running it updates an existing install.

<Tabs>
  <TabItem label="Linux / macOS">
    ```bash
    curl -fsSL https://zz-lang.pages.dev/install.sh | sh
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    irm https://zz-lang.pages.dev/install.ps1 | iex
    ```
  </TabItem>
  <TabItem label="From source">
    ```bash
    git clone https://github.com/zaidejjo/zz
    cd zz
    cargo install --path crates/zz_cli
    ```
  </TabItem>
</Tabs>

Pin a version with `ZZ_VERSION` (`$env:ZZ_VERSION` on Windows):

```bash
curl -fsSL https://zz-lang.pages.dev/install.sh | ZZ_VERSION=v0.1.6 sh
```

Verify the install:

```bash
zz --version
zz setup    # PATH + shell completions for bash/zsh/fish (run once)
```

`zz setup` creates `~/.zz/bin`, wires it into your shell, and installs
tab completion (`zz run <TAB>` completes `.zz` files). Installed from
source instead? The first `zz` run heals `~/.zz/bin` automatically and
points you at `zz setup` when PATH needs it.

Install a project as a tool:

```bash
zz install --path .   # release-build this project into ~/.zz/bin
```

## Hello world

Create `hello.zz`:

```zz
name := input("What is your name? ")
println("Hello, {name}!")
```

Run it:

```bash
zz run hello.zz
```

## The REPL

Start an interactive session with bare `zz`:

```
ZZ 0.1.0 — type-based language
Type expressions to evaluate. :help for commands.
zz> x := 42
42
zz> x + 1
43
zz> func add(a: int, b: int) -> int { a + b }
<func add>
zz> add(3, 4)
7
```

Useful REPL commands: `:help`, `:type expr` to show a type, `:clear` to reset bindings, `:quit` to exit.

## Your first real program

```zz
func factorial(n: int) -> int {
    if n <= 1 { 1 } else { n * factorial(n - 1) }
}

println("5! = {factorial(5)}")
```

```
5! = 120
```

## Check, fix, format

ZZ ships its diagnostics as commands:

```bash
zz check src/     # report errors and warnings
zz fix src/       # apply safe auto-fixes
zz fmt src/       # format files in place
zz eval "1 + 2"   # evaluate one expression → 3
```
